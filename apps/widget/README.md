# @roadly/widget

Embeddable, self-mounting widget. End users submit and vote on Feature Requests from inside a host app.

Not yet implemented — see `context/architecture.md` for the intended stack (React + Redux Toolkit/RTK Query, Vite library-mode build, Radix + Tailwind, Shadow DOM mounting) and the Shadow DOM constraints that must be designed around from the start. This app's own folder structure and conventions will be documented here once implementation begins.
